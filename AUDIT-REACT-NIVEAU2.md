# Audit et enrichissement — React Niveau 2

## Référence pédagogique

Le parcours JavaScript reste la référence : cours structurés, exercices réguliers, difficultés progressives, indices en trois étapes, corrections expliquées, statut À revoir, progression et projets.

## État après enrichissement

### React Niveau 2 — Fondamentaux React

- 6 leçons
- 24 exercices (4 par leçon)
- 10 questions d’évaluation finale
- 1 projet Task Manager renforcé
- 9 critères structurels pour le projet
- révision intégrée au moteur React commun
- progression des leçons historiques préservée

## Répartition des exercices

1. Rendu conditionnel — 4 exercices
2. Listes et key — 4 exercices
3. Formulaires contrôlés — 4 exercices
4. Tableaux dans le state — 4 exercices
5. Communication entre composants — 4 exercices
6. Organisation des composants — 4 exercices

## Variété pédagogique

Les exercices utilisent plusieurs formats :

- QCM
- vrai / faux
- prédiction de résultat
- atelier React / JSX
- correction de bugs
- refactorisation
- mise à jour immuable
- analyse d’architecture

Chaque exercice du niveau possède trois indices progressifs et une correction expliquée via le moteur partagé déjà utilisé pour React Niveau 1 et dérivé du système JavaScript.

## Projet de niveau

Le Task Manager valide désormais notamment :

- state des tâches
- saisie contrôlée
- rendu avec map
- key stable
- suppression avec filter
- interaction utilisateur
- modification d’une tâche avec map
- filtrage Toutes / Actives / Terminées
- extraction d’au moins un composant enfant

La plateforme effectue une validation structurelle et ne prétend pas exécuter un véritable environnement Vite/React.

## Migration de progression

Les leçons déjà terminées restent terminées. Les 24 nouveaux exercices alimentent une mesure de maîtrise distincte et la section Révision, sans transformer brutalement un ancien niveau complété en niveau incomplet.
