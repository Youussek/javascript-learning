# Audit — React Niveau 5 : exercices finaux

## Résultat

Le Niveau 5 « React professionnel » est maintenant enrichi avec le même format pédagogique que les niveaux 1 à 4.

- 8 leçons
- 32 exercices
- 4 exercices par leçon
- 10 questions d’évaluation finale
- 8 ateliers React reliés au React Studio
- 1 projet final interactif « Application React de production »

## Répartition

1. React + TypeScript — 4 exercices
2. Dépendances et package.json — 4 exercices
3. Tests d’intégration — 4 exercices
4. Résilience / loading / error / empty / retry — 4 exercices
5. Sécurité frontend — 4 exercices
6. Performance de production / lazy / Suspense — 4 exercices
7. Build / preview / déploiement Vite — 4 exercices
8. Maintenance / dette technique / refactor — 4 exercices

## Formats utilisés

- QCM
- vrai/faux
- prédiction / analyse de code
- ateliers React avec validation structurelle
- ateliers reliés au React Studio
- diagnostic de pratiques professionnelles

Chaque exercice possède trois indices progressifs et une correction expliquée.

## Vérifications exécutées

- syntaxe de tous les fichiers JavaScript avec `node --check`
- 32 exercices Niveau 5 détectés
- 4 exercices pour chacune des 8 leçons
- 10 questions d’évaluation
- aucun ID dupliqué dans les exercices/évaluations React
- aucun exercice rattaché à une leçon inexistante
- trois indices pour chaque exercice
- toutes les expressions régulières de validation compilent
- toutes les solutions des exercices `reactcode` satisfont leurs propres critères
- les presets React Studio du Niveau 5 sont présents
